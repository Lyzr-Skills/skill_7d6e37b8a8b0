# Asset Inventory Framework

Assets are structured systematically rather than generated ad-hoc. Every asset must serve a defined execution outcome.

## Asset Model fields
- **Asset ID**: Unique identifier.
- **Purpose**: Why does this asset exist?
- **Audience**: Who reads/interacts with this?
- **Message**: Which core message adaptation does this express?
- **CTA**: The specific action to take.
- **Format**: File format/platform layout.
- **Owner**: Person/agent responsible.
- **Status**: REQUIRED, OPTIONAL, IN_PROGRESS, APPROVED, MISSING.
- **Dependency**: Another asset or task ID that must be finished first.
