# Campaign Framework

This framework governs how approved strategy and positioning map to campaign execution without altering the core strategic assumptions.

## Core Flow
Approved Strategy (Target, Objective) → Approved Positioning & Messaging → Campaign Execution Skill → Campaign Plan.

## Hard Rules
- Campaign Execution MUST NOT silently modify the approved ICP, positioning, or strategic objective.
- If a constraint is detected (e.g. channel cannot reach ICP), trigger: `STRATEGIC REVIEW REQUIRED`.

### Permitted Execution Changes
- Channel adaptation (formatting core messaging for LinkedIn vs email).
- Asset formats (choosing landing page layouts, copy adjustments).
- CTA visual presentations.
- Launch timing and sequencing.

### Prohibited Strategic Changes (Requires Strategic Review)
- Redefining ICP characteristics.
- Altering positioning or value propositions.
- Redefining the core campaign objective or goals.
