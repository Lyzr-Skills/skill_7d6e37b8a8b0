# Measurement Framework

Differentiates metrics explicitly and groups them into hierarchical layers.

## Outputs vs Outcomes
- **Output metrics**: Measure work done (e.g. 10,000 ad impressions, 3 blog posts published).
- **Outcome metrics**: Measure business value generated (e.g. 15 qualified opportunities created).

## Metric Hierarchy
1. **North Star Metric**: The ultimate objective (e.g., Qualified Pipeline Value).
2. **Primary Success Metric**: The main signal of campaign success (e.g., Booked Demos).
3. **Secondary Metrics**: Performance drivers (e.g., Click-through rate, cost per demo).
4. **Diagnostic Metrics**: Granular diagnostics (e.g., email open rate, page load time).
5. **Guardrail Metrics**: Protection against negative externalities (e.g., unsubscribes, cost per acquisition ceiling, bounce rate).
