# Launch Readiness Evaluator

Final sign-off gates before moving campaign status to READY.

## Readiness Gates

### Gate 1 — Strategy
- [ ] Approved strategy reference exists.
- [ ] ICP is explicitly defined.
- [ ] Campaign objective is aligned with the strategic goal.

### Gate 2 — Messaging
- [ ] Approved positioning reference exists.
- [ ] Messaging adapted to selected channels.
- [ ] CTA aligns with the objective.

### Gate 3 — Assets
- [ ] All required assets are completed and approved.
- [ ] Asset dependencies are fully resolved.

### Gate 4 — Measurement
- [ ] Measurement preflight is READY.
- [ ] Conversion tracking works.
- [ ] Targets and baselines are defined.

### Gate 5 — Launch
- [ ] No blocking task dependencies exist.
- [ ] Audience segment is configured in the channel platform.
- [ ] Destination links are QA tested.

## Evaluation Outcome
- **LAUNCH READY**: All gates passed.
- **BLOCKED**: One or more gates failed. Do not launch.
